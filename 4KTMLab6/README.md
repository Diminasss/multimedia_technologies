# Лабораторная работа №6. Фурье-фильтрация изображений

Программа выделяет высокочастотные детали изображения в частотной области и сравнивает результат с детектором границ Кэнни. Обработка выполняется по каналу яркости пространства LAB.

## Что реализовано

- двумерное прямое и обратное преобразования Фурье;
- визуализация амплитудного спектра в децибелах;
- идеальный фильтр высоких частот для четырех частот среза;
- ФВЧ Баттерворта для пяти частот среза;
- исследование порядков фильтра 1, 2, 4 и 6;
- бинаризация результата с несколькими порогами;
- сравнение частотной фильтрации с методом Canny.

## Входные данные

Скрипт ожидает файл `суслик.jpg` в текущем каталоге. Этого изображения сейчас нет в репозитории, поэтому перед запуском добавьте его в папку `4KTMLab6` либо измените путь в вызове `load_and_prepare_image()`.

После запуска будут созданы изображения `01_original_suslik.png` — `07_final_comparison.png`, включая исходный спектр, результаты фильтров и итоговое сравнение методов.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Частоты среза, порядок фильтра Баттерворта и пороги бинаризации задаются внутри функции `main()`.
