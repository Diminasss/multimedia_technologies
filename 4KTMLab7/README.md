# Лабораторная работа №7. Восстановление смазанных изображений

Работа посвящена моделированию смаза и обратной фильтрации изображений. Сравниваются фильтр Винера и итерационный метод Люси — Ричардсона, а также исследуется влияние ошибки в оценке функции рассеяния точки (PSF).

## Части работы

### `Part1.py` — восстановление с известной маской

Создается вертикальный неравномерный смаз маской размером 15 пикселей. Изображение восстанавливается фильтром Винера и методом Люси — Ричардсона. Дополнительно проверяется влияние JPEG-сжатия на результат обратной фильтрации.

### `Part2.py` — ошибка в оценке PSF

Истинная маска размером 15 сравнивается с ошибочными оценками размером 13 и 25 пикселей. Для каждой оценки выполняется восстановление обоими методами.

### `Part3.py` — обработка реального смаза

Для реального изображения строится линейная PSF с настраиваемыми длиной и углом. Фильтр Винера исследуется при разных оценках дисперсии шума, а метод Люси — Ричардсона — при разном числе итераций.

## Входные данные

Для запуска нужны изображения, которых сейчас нет в репозитории:

- `текст.png` — для `Part1.py` и `Part2.py`;
- `смазана.jpg` — для `Part3.py`.

Поместите их в каталог `4KTMLab7` или измените пути в соответствующих скриптах.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install numpy matplotlib opencv-python scikit-image
python Part1.py
python Part2.py
python Part3.py
```

Скрипты показывают сравнительные графики в окнах Matplotlib. `Part1.py` сохраняет смазанное JPEG-изображение, а `Part3.py` — лучшие варианты восстановления методами Винера и Люси — Ричардсона.
