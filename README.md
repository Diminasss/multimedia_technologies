# Мультимедийные технологии

Репозиторий с семью лабораторными работами по цифровой обработке аудиосигналов и изображений. В проектах рассматриваются генерация и спектральный анализ звука, фильтрация во временной и частотной областях, синтез шумоподобного аудио, управление контрастностью, выделение границ и восстановление смазанных изображений.

## Технологии

- Python 3;
- NumPy и SciPy для численных методов и обработки сигналов;
- Matplotlib для графиков и визуализации;
- SoundFile для чтения и записи аудио;
- scikit-image и OpenCV для обработки изображений.

## Запуск

Каждая лабораторная работа является самостоятельным проектом со своим набором зависимостей. Перейдите в нужную папку, создайте виртуальное окружение и установите зависимости:

```powershell
cd 4KMTLab1
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Для другой работы замените имя каталога. У лабораторной №7 файл зависимостей отсутствует; команда установки приведена в ее [README](4KTMLab7/README.md).

Скрипты используют относительные пути, поэтому запускать их следует из каталога соответствующей лабораторной. Для работ №6 и №7 необходимо предварительно добавить входные изображения, перечисленные в их README.
